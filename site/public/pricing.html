Questions people ask

Why pay if it's open source?

You don't have to. The paid tiers fund development and unlock convenience features: the advisor, narration, shopping links. Their code is in the same repository under the same MIT license; the app gates them behind a license key as a matter of honour, not enforcement.

How do license keys work?

A key is a short string signed with an Ed25519 private key that only the issuing tool holds. The app verifies it locally with the public key baked into the binary; there is no activation server, no device binding and no seat count to sync. Supporter keys never expire and are never checked online. Pro, Team and Enterprise keys carry an expiry date: when a subscription key is within 30 days of expiry, the app contacts innards.app/api/license/refresh once at startup to fetch a renewed key, sending only the key itself.

What does "pay what you want" mean for Supporter?

The suggested price is $9. Pay $5 if that's what it's worth to you, or more if you'd like to fund the next feature. Every Supporter key unlocks exactly the same things.

What does the narration feature actually do?

It rephrases the structured findings into a short narrative in your language and at your level, via the Claude API, using an API key you provide and pay for directly. It does not diagnose anything itself; the rules do. See what is sent.

What is Threadwise?

The open-source CRM the Team dashboard is built on. Team customers get a hosted workspace; Enterprise customers run the same backend on their own infrastructure.

Do you offer reviewer or educational keys?

Yes. Email Eugene with a sentence about what you need.
